# 채널 브랜딩

## 1. 이름

기존 채널을 그대로 쓰되 이름·프로필·배너를 교체한다.
요구 조건은 **확장성**(캐릭터를 계속 추가), **환영하는 어감**, **애니 제목 같은 결**.

### 실제 선례 (이 컨셉과 같은 구조의 작품)

| 구문 | 작품 |
|---|---|
| 「우리 집 ○○」 | 『우리 집 여우신령님』 — 여우신이 집에 눌러살며 집안을 돌봄 |
| 「○○네 집 ○○」 | 『코바야시네 메이드래곤』 — 드래곤이 메이드로 집안일 |
| 「어서 오세요 ○○」 | 『NHK에 어서 오세요』, 『어서 오세요 실력지상주의 교실에』 |
| 셰어하우스형 | 『요괴 아파트의 우아한 일상』 — 이종족들과 한집살이 |

「우리 집 + 사람 아닌 존재 + 집안일」은 이미 장르로 굳어 있다.
**집요정(브라우니·집귀신)** 설정을 쓰면 "왜 애니 캐릭터가 내 집 살림을 알려주나"가
설명되고, 캐릭터를 늘릴 때 명분도 자동으로 생긴다.

### 후보

| 안 | 이름 | 평 |
|---|---|---|
| **A** | **우리집엔 요정이 산다** | 『우리 집 여우신령님』 구조 그대로. 이름만 보고 컨셉이 읽힌다. 요정'들'로 확장 |
| B | 어서 와, 우리집 | 따뜻하고 짧다. 다만 살림 신호가 없어 브이로그로 오인될 수 있다 |
| C | 같이 살자 | 2어절로 강하지만 로맨스물·드라마와 검색 충돌. 비추 |
| D | 우리집 요정들 | A의 짧은 형. 핸들·구어체용 |

**채택: A**, 짧게 부를 땐 D.
채널 검색 유입은 채널명이 아니라 **영상 제목·태그**에서 나오므로,
이름은 컨셉 전달과 확장성만 보면 된다.

- 핸들: `@ourhome_fairy`
- 시안 배너: `banner_A.png`(A안) / `banner_B.png`(B안)

## 5. episode-001 업로드 세트

**제목**
```
락스로는 안 지워지는 변기 자국의 정체
```
대안 — `변기 물때인 줄 알았는데 요석이었습니다` / `구연산 뿌리고 휴지만 덮으면 됩니다`

**설명**
```
변기에 낀 누런 자국은 물때가 아니라 '요석'입니다.

소변 속 요소가 세균을 만나 암모니아가 되고, 물이 알칼리로 변하면서
칼슘·마그네슘이 결정으로 굳은 것 — 그래서 알칼리인 락스로는 녹지 않습니다.
락스는 위에 덮인 색소만 표백할 뿐 결정은 그대로 남습니다.

구연산은 그 금속 이온을 붙잡아 물에 녹는 형태로 바꿉니다. 이걸 킬레이션이라고 해요.
chelate의 어원이 그리스어 chele(게 집게)인 것도 그래서입니다. 🦀

준비물 — 구연산, 분무기, 화장지
1. 구연산수를 자국에 뿌린다
2. 화장지를 덮는다
3. 기다렸다 벗기고 솔로 가볍게

⚠️ 산성 세제와 락스(염소계)를 섞으면 염소가스가 발생합니다. 절대 함께 쓰지 마세요.

#변기청소 #요석제거 #구연산
```

**태그**
`변기청소` `변기물때` `요석` `요석제거` `구연산` `구연산청소` `욕실청소`
`화장실청소` `살림꿀팁` `청소꿀팁` `자취살림` `홈클리닝`

**고정 댓글**
```
⚠️ 구연산(산성)과 락스(염소계)는 절대 섞지 마세요. 염소가스가 나옵니다.
락스를 먼저 썼다면 물로 충분히 헹군 뒤에 구연산을 쓰세요.

세린이 다음엔 뭘 알려주면 좋을까요?
```

**썸네일** — 영상 첫 프레임(앉아서 솔 든 컷)이 그대로 쓰인다.
