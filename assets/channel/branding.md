# 채널 브랜딩

## 1. 이름

기존 채널을 그대로 쓰되 이름·프로필·배너를 교체한다.
요구 조건은 **확장성**(캐릭터를 계속 추가), **환영하는 어감**, **애니 제목 같은 결**.

### 실제 선례 (이 컨셉과 같은 구조의 작품)

| 구문 | 작품 |
|---|---|
| 「우리 집 ○○」 | 『우리 집 여우신령님』 — 여우신이 집에 눌러살며 집안을 돌봄 |
| 「○○네 집 ○○」 | 『코바야시네 메이드래곤』 — 드래곤이 메이드로 집안일 |
| 「어서 오세요 ○○」 | 『NHK에 어서 오세요』, 『어서 오세요 실력지상주의 교실에』 |
| 셰어하우스형 | 『요괴 아파트의 우아한 일상』 — 이종족들과 한집살이 |

「우리 집 + 사람 아닌 존재 + 집안일」은 이미 장르로 굳어 있다.
**집요정(브라우니·집귀신)** 설정을 쓰면 "왜 애니 캐릭터가 내 집 살림을 알려주나"가
설명되고, 캐릭터를 늘릴 때 명분도 자동으로 생긴다.

### 후보

| 안 | 이름 | 평 |
|---|---|---|
| **A** | **우리집엔 요정이 산다** | 『우리 집 여우신령님』 구조 그대로. 이름만 보고 컨셉이 읽힌다. 요정'들'로 확장 |
| B | 어서 와, 우리집 | 따뜻하고 짧다. 다만 살림 신호가 없어 브이로그로 오인될 수 있다 |
| C | 같이 살자 | 2어절로 강하지만 로맨스물·드라마와 검색 충돌. 비추 |
| D | 우리집 요정들 | A의 짧은 형. 핸들·구어체용 |

**채널명은 사용자가 직접 설정 완료.** 아래 표는 판단 근거 기록용으로 남긴다.
채널 검색 유입은 채널명이 아니라 **영상 제목·태그**에서 나오므로,
이름은 컨셉 전달과 확장성만 보면 된다.

- 핸들: `@ourhome_fairy`
- 시안 배너: `banner_A.png`(A안) / `banner_B.png`(B안)

## 6. 고정 댓글 — 작성은 자동, 고정은 수동

YouTube Data API v3의 댓글 관련 엔드포인트는 이게 전부다.

| 되는 것 | 안 되는 것 |
|---|---|
| `commentThreads.insert` — 최상위 댓글 작성 | **고정(pin)** — 엔드포인트 자체가 없음 |
| `comments.insert` — 대댓글 | |
| `comments.update` — 본문 수정 | |
| `comments.setModerationStatus`, `comments.delete` | |

그래서 **댓글을 다는 것까지는 자동**이고, **고정 클릭 한 번만 수동**이다.
`src/uploader.py`의 `post_comment()`가 업로드 직후 `metadata.pinned_comment`를
달고, 스튜디오에서 ⋮ → '고정'을 누르라고 안내한다.

> `commentThreads.insert`는 `youtube.force-ssl` 스코프를 요구한다.
> `SCOPES`에 추가했으므로 **기존 토큰은 무효다.**
> `python3 -m src.uploader --auth-only`로 한 번 재인증할 것.

**고정 댓글 본문**
