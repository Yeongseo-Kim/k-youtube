# 한의원 실제 시술 관찰 노트

국내 한의원 유튜브 영상을 실제로 열어 화면을 확인하고 정리했다.
표기: **[확인]** 화면에서 직접 본 것 · **[문헌]** 설명란·기사 근거 · **[추정]** 둘로 미룬 것.
영상 파일은 받지 않았다. 관찰만 하고 우리 프롬프트에 반영한다.

## 우리가 틀렸던 것

- **환자복** — [확인] 침·추나 모두 **평상복 그대로**다. 상의를 걷어 올리거나 바지를 살짝 내릴 뿐
  갈아입지 않는다. 우리는 전부 환자복으로 만들었다
- **부항 컵 개수** — [확인] 실제는 **12~14개**. 척추 좌우 세로 2열 + 어깨 좌우. 우리는 6개였다
- **부항 붙이는 순서** — [확인] **어깨(위) → 허리(아래)** 방향
- **추나 자세** — [확인] 관찰한 영상은 **측와위(옆으로 누움)**, 수근부를 천장관절에 얹고 체중을
  수직으로 싣는다. 드롭 테이블은 안 보였다. 우리는 복와위 + 등 중앙이었다
- **장갑** — [확인] 침에는 **맨손**(소매 걷은 맨 팔뚝, 손목시계). 부항에는 **흰 장갑**을 낀다.
  우리는 반대로 만들었다
- **한약 파우치** — [추정] 은박 파우치에 한글 라벨, 종이 쇼핑백이나 박스째 **두 손으로** 건넨다

## 맞았던 것

- [문헌] 침관 사용은 기본값에 가깝다. 강의 영상의 주제 자체가 "침관을 써도 되나"일 만큼 표준
- [확인] 전침 리드선은 **빨간 집게**로 침대에 물리고, 기기는 베드 옆 **다이얼 줄지어 달린 흰 박스**
- [문헌] 진맥은 검지·중지·약지 **세 손가락**을 촌·관·척에 나란히
- [확인] 컵 안으로 피부가 불룩 빨려 올라오는 그림

## 카메라 문법 (실제 영상들이 쓰는 것)

1. **45도 사선 부감** — 시술 전체와 베드·기기까지 담는 설정샷. 전침·부항 영상이 이걸로 시작
2. **베드 높이 타이트 클로즈업** — 손과 접촉면만. 추나 영상은 거의 전부 이 앵글
3. **매크로 인서트** — 컵 안의 피부, 침대에 물린 클립

조명은 [확인] **주광색 형광등, 그림자 약한 평면광**. 흰 벽, 베이지 매트, 연두 커튼.
컷 길이는 설명 영상 8~15초, ASMR 20~60초 롱테이크, 홍보 영상 3~6초.
우리는 홍보 영상 문법(3~6초)을 따르되 손동작 핵심 컷 하나만 8~12초로 둔다.

## 실제로 하는 말 (그대로 확보한 것)

- "이렇게 자극이 더 많아지게 되고 톡톡 튀는 느낌이 나면서" (전침)
- "빠져나가는 느낌인데요" (부항, 한의사)
- "시원해요" (부항, 환자)
- "일반인은 절대 따라하지 마세요" (추나 설명란)
- "하루 2번~3번 의사의 처방에 따라" (한약)

부항의 "빠져나가는 느낌"은 우리가 표정으로 만들려던 바로 그것이다. 대사로 쓸 수 있다.

## 프롬프트 반영 사항

1. 침 — 맨손·소매 걷은 팔뚝, 침관을 세우고 검지로 톡 친 뒤 관을 빼는 2단 동작, 환자 옆에 서서
2. 전침 — 빨간 집게 리드선, 다이얼 달린 흰 박스형 기기, 케이블이 베드 위로 늘어짐
3. 부항 — 투명 컵 12개 내외, 척추 좌우 2열 + 어깨, 위에서 아래 순서, **흰 장갑**
4. 추나 — 평상복 측와위, 수근부를 천장관절에, 평면 베드
5. 진맥 — 세 손가락, 맥침, 시선 내리깔고 20~30초. 촌관척 장부 단정 대사 금지
6. 한약 — 은박 파우치 + 한글 라벨, 두 손으로 건넴, "하루 두세 번" 수준의 일반 안내만
7. 복장 — **평상복 기조**로 통일. 환자복은 추나 정도에만

## 남은 구멍

- 자막 전문 미확보 (유튜브가 외부 요청에 timedtext를 안 준다)
- 진맥·한약은 실장면을 못 봐서 문헌·추정 비중이 높다
- 침관 자침 클로즈업 실장면 미확인
