## ElevenLabs 계정 상태 (2026-08-28 확인)

**ElevenLabs 계정: 조회 불가 — API 키가 무효화됐습니다.**

`GET /v1/user`, `/v1/user/subscription`, `/v1/voices` **전부 401
`invalid_api_key`**. 플랜·글자 사용량을 읽을 수 없어 수치를 적지 못합니다.

키가 죽은 것이지 권한 범위 문제가 아닙니다. 같은 세션 안에서:

| 시각 | 호출 | 결과 |
|---|---|---|
| 앞서 | `/v1/voices` (음성 목록) | 200 — 보유 34개 + 라이브러리 조회 성공 |
| 앞서 | `/v1/text-to-speech/…` ×16 | 200 — 오디션 4 + 대사 12줄 전부 생성 |
| 지금 | `/v1/voices`, `/v1/user` | **401** |

읽기 전용 엔드포인트까지 401이 나므로 스코프 제한이 아니라 **키 자체가
회수·재발급된 것**으로 보입니다. 이 세션에서 API 키를 대화창에 붙여넣은 이력이
있어 재발급을 여러 차례 권고했으므로, 그 조치가 방금 이뤄졌을 가능성이 높습니다.

**조치** — `.env`의 `ELEVENLABS_API_KEY`를 새 키로 교체해야 합니다.
이미 생성해 커밋한 음성 파일(오디션 4개, 대사 12줄)은 영향이 없습니다.

## ElevenLabs 무료 사용 관련 결정 — 기록 없음

이 세션에 "ElevenLabs를 무료로 쓰기로" 한 **합의는 없었습니다.** 관련 있는
기록은 이것뿐입니다.

- 세린 보이스를 고르던 중 사용자가 한국어 음성을 더 찾으며
  "무료로 들을 수 있는 거?"라고 물은 적이 있음 — 음성 후보를 미리 들어볼 수
  있는지에 대한 질문이었고, 요금제를 무료로 유지하자는 결정은 아니었음
- 무료 플랜에서는 **라이브러리 음성을 API로 쓸 때 402가 반환**되며 Starter
  이상이 필요함을 확인했음. 이후 작업은 라이브러리 음성으로 계속 진행됐으므로,
  실제로는 유료 플랜 위에서 돌아간 셈

즉 무료 사용을 전제로 한 합의는 없고, 오히려 무료 플랜의 제약을 확인하고
그것을 넘어선 상태에서 작업했습니다.
